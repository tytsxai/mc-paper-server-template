【测试步骤】

1. 加入服务器
   → 应该立即看到完整的欢迎消息（MOTD）
   → 消息应包含所有插件功能说明和QQ群号

2. 测试命令（在游戏中执行）：

   /motd
   → 应该显示完整的欢迎消息

   /rules
   → 应该显示服务器规则

   /kits
   → 应该显示可用的礼包列表

   /kit welcome
   → 应该获得新手礼包（木制工具、食物、建材）

   /kit daily
   → 应该获得每日签到礼包（或显示冷却时间）

   /help
   → 显示帮助信息

3. 测试新玩家加入
   → 如果是新玩家首次加入
   → 全服应该看到欢迎广播
   → 消息应包含新手礼包提示和QQ群号

4. 测试圈地功能
   /claim
   → 应该能够圈地

5. 测试传送功能
   /sethome test
   /home test
   /spawn

6. 测试便捷功能
   /sit
   /chestsort
   /pp
