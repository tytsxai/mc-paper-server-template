📝 使用方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 手动触发新人教程：
   ./newbie-guide.sh <玩家名> tutorial

2. 发送快速帮助：
   ./newbie-guide.sh <玩家名> help
   ./newbie-guide.sh <玩家名> help commands
   ./newbie-guide.sh <玩家名> help claim
   ./newbie-guide.sh <玩家名> help social

3. 测试配置：
   ./test-newbie-guide.sh

4. 在游戏中测试：
   /motd          - 查看欢迎消息
   /rules         - 查看服务器规则
   /kit welcome   - 领取新手礼包
   /kit tools     - 领取工具包

5. 重载配置：
   /essentials reload  - 重载 Essentials
   /lagg reload        - 重载 ClearLag

⚠️ 注意事项
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 需要重载配置才能生效：
   /essentials reload
   /lagg reload

2. 或者重启服务器：
   ./stop-graceful.sh
   ./start.sh

3. 确保已设置新手出生点：
   /setspawn newbies

4. 确保新玩家有权限领取礼包：
   /lp group default permission set essentials.kits.welcome true
   /lp group default permission set essentials.kits.tools true

5. 如果使用 newbie-guide.sh 脚本，需要：
   - 启用 RCON（server.properties）
   - 配置正确的 RCON 密码
   - 安装 mcrcon 工具
