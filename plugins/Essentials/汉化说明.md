## 使用说明

### 重新加载配置
如需重新加载语言文件，使用命令：
```
/ess reload
```

### 验证汉化是否生效
1. 重启服务器或执行 `/ess reload`
2. 执行任意 Essentials 命令（如 `/balance`）
3. 检查输出是否为中文

### 自定义消息
如需自定义某些消息文本：
1. 编辑 `messages_zh.properties` 文件
2. 找到对应的键值对
3. 修改等号后面的中文文本
4. 保存并执行 `/ess reload`

## 技术说明

### 符号链接
为了同时支持 `zh` 和 `zh_CN` 语言代码，创建了符号链接：
```
messages_zh_CN.properties -> messages_zh.properties
```

### 字符编码
所有语言文件都使用 **UTF-8** 编码，确保中文正常显示。
