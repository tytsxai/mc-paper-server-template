📦 项目名称: PlayerMenu
🏷️  版本号: 1.0
📅 完成日期: 2025-10-07
✅ 状态: 已部署并运行

================================================================================
                              🎯 项目目标
================================================================================

为Minecraft服务器玩家提供一个直观的GUI菜单系统，减少记忆和输入指令的负担，
提升玩家体验，降低新手学习成本。

================================================================================
                              ✨ 核心功能
================================================================================

✅ 8大功能菜单分类
✅ 41+个快捷功能入口
✅ 5个命令别名 (/menu, /m, /菜单, /cd, /gui)
✅ 完全中文界面
✅ 轻量级设计 (仅16KB)
✅ 零配置运行

================================================================================
                              🚀 快速开始
================================================================================

1. 玩家使用:
   - 游戏中输入: /m 或 /menu
   - 点击菜单图标使用功能

2. 管理员:
   - 确认权限组已分配 `playermenu.use`
   - 如需重新编译插件，请参考 PlayerMenuPlugin/README.md（源码环境）

================================================================================
                              🎮 使用命令
================================================================================

/menu   - 打开玩家菜单
/m      - 打开玩家菜单 (简短别名)
/菜单   - 打开玩家菜单 (中文别名)
/cd     - 打开玩家菜单 (快捷别名)
/gui    - 打开玩家菜单 (GUI别名)

================================================================================
                              🛠️ 维护说明
================================================================================

日常维护: 无需维护，自动运行

更新插件:
  1. cd /root/minecraft-server/PlayerMenuPlugin
  2. mvn clean package
  3. cp target/PlayerMenu-1.0.jar ../plugins/
  4. 重启服务器

权限管理:
  - 添加权限: lp group <组名> permission set playermenu.use true
  - 移除权限: lp group <组名> permission unset playermenu.use

================================================================================
                              ❓ 常见问题
================================================================================

Q: 为什么点击某些功能没有反应？
A: 可能是没有相应的权限，请联系管理员。

Q: 如何关闭菜单？
A: 点击"关闭菜单"按钮或按ESC键。

Q: 菜单命令别名有哪些？
A: /menu, /m, /菜单, /cd, /gui

Q: 插件会影响服务器性能吗？
A: 不会，插件非常轻量，几乎不占用资源。
